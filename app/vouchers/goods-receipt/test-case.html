Test 1 — Header fields

Voucher type: GRN (Goods Receipt Note)

Preconditions:
- User is logged into the Rachis tenant
- At least one Vendor/Supplier exists in the tenant
- At least one Item exists in the Item master with Rate and GST% set
Test data:
- Vendor: (to be selected from tenant)
- GRN date: current date
- Expected receipt date: current date + 1 day
- Place of supply: to match vendor's GST state

Steps

  1. Open a new GRN voucher
  2. Verify Top block shows: Vendor field, GRN date, Expected delivery date, Place of supply, Payment terms
  3. Verify Title area shows voucher type and voucher number
  4. Click "▸ More details" — reveal PO number and similar secondary fields
  5. Select a Vendor whose GST state is known
  6. Verify Place of supply shows state name with 2-digit code (e.g. "Kerala (32)")
  7. Verify Payment terms can be left blank and GRN still saves

Expected result

  • All header fields present and functional
  • Vendor selection populates Place of supply with state name and code
  • Payment terms optional — GRN saves even when blank
  • "More details" disclosure reveals PO and secondary fields
