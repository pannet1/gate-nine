Test 1 — Header fields

Voucher type: Credit Note

Preconditions:
- User is logged into the Rachis tenant
- At least one Customer exists in the tenant
- At least one previously posted Sales Invoice exists with GST rates configured
Test data:
- Customer: (to be selected from tenant, must have existing invoice)
- Credit Note date: current date
- Reason for credit: (free-text note)
- Original invoice number: (to reference the parent invoice)

Steps

  1. Open a new Credit Note voucher
  2. Verify Top block shows: Customer field, Credit Note date, Place of supply, Payment terms
  3. Verify Title area shows the voucher type on one line and the voucher number just below it
  4. Click/expand "▸ More details" link/disclosure — reveal original invoice reference and reason fields
  5. Select the Customer who has the parent invoice
  6. Verify Place of supply shows the state name with its 2-digit code, e.g. "Tamil Nadu (33)"
  7. Verify the original invoice reference is correctly populated from the parent invoice
  8. Verify Payment terms can be left blank and the Credit Note still saves

Expected result

  • All header fields present and functional
  • Customer selection populates Place of supply with state name and code
  • Original invoice reference correctly populated from parent invoice
  • Payment terms optional — Credit Note saves even when blank
  • "More details" disclosure reveals original invoice reference and reason fields
