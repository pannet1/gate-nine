Rachis has already been tested a thousand times. This is not a bug hunt. It is for watching, and for stopping.

A black box with a visible window

No source access, no internal APIs, no database. A human writes the brief, a human approves the data, and a human decides what they saw.

  • Never headless. headless=False in every recording. A loop that hides the window defeats the only purpose of the project.
  • Playwright replays; the human watches. Nothing prompts, nothing waits for a keystroke, nothing is synthesised at run time.
  • The human owns the verdict. The runner reports that a script threw. It never declares a product pass or fail.
  • Login is infrastructure. One saved auth.json per system, loaded by every recording. No recording carries a login of its own.

And the eight it refuses

Never headless

Never a guessed URL

Never a written selector

Never a placeholder command

Never an AI verdict

Never a committed secret

Never an invented test

Never a window left open

  • Never headless. Seeing data entered is the entire purpose. A loop that hides the window defeats the only reason this project exists.
  • Never a guessed URL. It is read from url.txt, or not at all. No route is extrapolated from a sibling case.
  • Never a written selector. Every locator in a recording came from a human clicking the live DOM. A guessed one is a false failure waiting to happen.
  • Never a placeholder command. Real paths and real values, ready to paste. <run> and <case> are useless.
  • Never an AI verdict. The runner reports that a script threw. Whether the product is right is judged by the person watching.
  • Never a committed secret. Credentials, saved cookies and evidence stay out of the repository.
  • Never an invented test. If it is not in the brief and the case list, it does not exist.
  • Never a window left open. A handoff closes every browser first, so the human's next command starts clean.

What the harness produces

A run that finds nothing missing prints a runnable command and exits. It never prints a guess at a URL or a route it inferred.

A case with no URLAsk for the URL first, because nothing can be recorded without knowing where to go.
A case with no recordingHand over the exact playwright codegen line, with the real output path and the real URL already read from disk.
A case ready to playNothing is asked. The browser opens and the recording runs.

from playwright.sync_api import sync_playwright

def run(playwright):
    browser = playwright.chromium.launch(
        headless=False)
    context = browser.new_context(
        storage_state="../auth.json")
    page = context.new_page()
    page.goto("https://rachis.co.in/accounting/
        sales-invoices/new/")
    page.get_by_role("group").filter(
        has_text="Customer*Invoice date*Due"
    ).get_by_label("Open options").click()
    # …two more exploratory clicks…
    page.close()

Where the work happens

app/main.py The whole loop in one file. Finds the run, requires the case list, calls tidy, and either hands over a command or plays every case back one at a time. This is the uv run python -m app.main you type.
tidy/workspace.py The interface the loop consumes. Holds the paths, so nothing else has to know the layout.
tidy/cases.py Reads and writes the case list, and the three-way split: recorded, missing a recording, missing a URL.
tidy/files.py Moves loose recordings into folders, fixes drifted filenames, rewrites the auth path. Never overwrites.
tidy/links.py Symlinks each case into the run, and points the shared auth file at the real one.
tidy/session.py Writes the work list a cold agent resumes from. Cases and state, never a verdict.
config.py · events.py Environment settings, and the remote event POST over Basic Auth. No local log is kept.
planner.py Finds the highest-numbered run folder, and the brief inside it. The filename is free.
driver.py Drove a plan file that no longer exists. Reads nothing that is still there.
diagnose.py Inspected that same deleted plan. Superseded.
app_tests/ One hundred thirty-five tests over a real temporary tree and real symlinks. No browser is opened.

What is still open

Open a card to read it. One is open at a time.

The case list
Its cases.yml lists sales-invoice, which belongs to run 001's Accounting brief. Run 002 is the Work Platform brief, so the loop opened a browser on the wrong form. The name comes from reading the brief and cannot be inferred. No command produces it. Until it is corrected, run 002 tests run 001's case.
A URL
The brief names Fortune Electronics or another Work-enabled tenant, and explicitly not Zigma. Nothing here extrapolates a route from a sibling case or falls back to the base URL. Until a human writes it into the case folder, that case cannot be recorded.
The recording
It contains three clicks, no form fill and no submit, so it can never pass: there is nothing in it to replay as a test. It needs re-recording with the form filled and submitted. The harness already reports this correctly: the browser opens, and the first recorded selector fails because the DOM has moved since.
Dead modules
driver.py and diagnose.py read a plan file that was deleted when recordings replaced it. Nothing imports them, but they are still importable and would fail if run. They should be deleted rather than left to mislead.
